# Demo script — 2 minutes 30 seconds

## 0:00–0:14 — cold open on the invention

Start on a prepared draft. Point to the native rail: commit_booking is not registered. Select Authorize this exact appointment and show commit_booking appear.

“The booking capability did not exist. Maya authorized one exact appointment, so the page registered it. That is ReferralArc.”

## 0:14–0:32 — credible real-world boundary

Reset. Show the case-source row.

“A clinician has already issued Maya’s MRI order. ReferralArc does not diagnose or create the referral. It handles the downstream administrative maze: requirements, availability, access, travel, estimates, intake, and consent.”

## 0:32–0:58 — structured discovery

Ask: “Read Maya’s case, apply every recorded hard constraint, compare eligible options, and explain the best administrative trade-off. Do not change state.”

Show 12 sites assessed, two eligible, the Northline/Harborlight trade-off, and the excluded-options disclosure. Expand it briefly to show the bounded provider text marked untrusted and ignored.

## 0:58–1:22 — reversible preparation

Ask: “Save Northline, draft only the minimum information already on file, and prepare its earliest eligible slot. Stop before confirmation.”

All safe preparation tools were available at turn start, so this path does not rely on mid-turn rediscovery. Show the shared visual state and live tool-call strip advance to the authorization boundary.

## 1:22–1:52 — human authority changes the API

Review exact facility, time, estimate, access, synthetic coverage signal, information used, and countdown. commit_booking is absent—not disabled. Select Authorize this exact appointment and show the successful native registration event.

“Human authority changes what the browser agent can discover.”

## 1:52–2:16 — commit and receipt

On a fresh turn, ask: “Re-read the current case state, then confirm only the exact appointment I approved.” Show the receipt, audit history, and commit_booking removal.

## 2:16–2:30 — close

“The invention is not AI scheduling. It is capability-lifetime consent: human authority becomes part of the browser’s native tool surface.” End on the live URL and public repository.

## Recording checklist

- Narrated public YouTube video
- Strictly under three minutes
- Browser chrome and live URL visible
- Native WebMCP first; human fallback mentioned
- Tool registry before and after authorization visible
- Registration event and automatic expiry explained
- No third-party music or unlicensed marks
- Captions reviewed
